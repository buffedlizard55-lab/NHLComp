Verification status of the price feeds

SourceNameStatusKnown limits
kalshi.candlesKalshi candlesticks (live tier)verifiedThe endpoint is named 'candlesticks'. The 2026-09-20 probes that returned 404 used the path segment 'candles', which does not exist -- that verdict was a wrong-URL error, not an unavailable feed, and is corrected here. Periods with no trades carry only price.previous plus bid/ask OHLC.
kalshi.historicalKalshi historical tier (markets + candlesticks before the cutoff)verifiedOnly settled/finalized contracts. Candle timestamps are period ends; the 'close' used here is the last 60-minute candle ending at or before the NHL scheduled start, so it can include trades up to puck drop.
kalshi.settled_marketsKalshi settled NHL game marketsverifiedThe exact timestamp of previous_yes_bid_dollars / previous_yes_ask_dollars is NOT documented by Kalshi. It is known only to precede settlement. Every bet built from it is therefore stamped verification_status='single_source_timing_unverified' and carries a caveat, rather than being presented as a precisely timestamped entry.
kalshi.trade_apiKalshi Trade API v2 (public market data)verifiedNHL liquidity is thin (observed bid/ask sizes of 5-555 contracts and $0 liquidity on many preseason games), so the execution model must model partial fills. Preseason markets may be sparse.
odds.the_odds_apiThe Odds APIrejectedNOT USABLE IN THIS BUILD: no API key is available in this environment and none may be invented. All sportsbook price work is therefore flagged, and closing-line value is computed against Kalshi instead.
How to read the P&L: BACKTEST rows use the Kalshi candlestick history (verification_status=kalshi_candle_close: entry at the last hourly candle ending at or before the scheduled start, with its timestamp). A handful of early rows were priced from Kalshi's undocumented previous_yes_ask and remain labelled single_source_timing_unverified; they are never relabelled. FORWARD TEST rows are opened only against a live quote and settle from the official NHL result. No sportsbook history exists in this system, so nothing is backtested against sportsbook odds; the DraftKings line from the NHL partner feed is recorded as a reference for forward signals only.
